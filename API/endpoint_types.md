| HTTP Method | Purpose                                   | Example               |
| ----------- | ----------------------------------------- | --------------------- |
| **GET**     | Retrieve/read data                        | `GET /students`       |
| **POST**    | Create new data                           | `POST /students`      |
| **PUT**     | Completely update/replace data            | `PUT /students/1`     |
| **PATCH**   | Partially update data                     | `PATCH /students/1`   |
| **DELETE**  | Delete data                               | `DELETE /students/1`  |
| **HEAD**    | Get headers without response body         | `HEAD /students`      |
| **OPTIONS** | Check which methods/options are supported | `OPTIONS /students`   |
| **TRACE**   | Diagnostic request tracing                | `TRACE /students`     |
| **CONNECT** | Establish a network tunnel                | `CONNECT example.com` |
